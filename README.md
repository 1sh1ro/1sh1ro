# 1sh1ro

**Systems Security · Fuzzing · Web3 · AI Agents**

I'm a master's student in **Electronic Information at Tianjin University**, with a background in cyberspace security. I work on software security, particularly where **operating systems, fuzzing, and program analysis** meet.

My current focus is understanding how low-level systems fail: reproducing kernel bugs, tracing them to their root causes, and turning findings into fixes or better testing approaches. I also explore **smart-contract security** and how LLMs and agents can assist with auditing, testing, and security research.

### Areas of interest

- **Kernel & filesystem security** — Linux and Rust-based operating systems, filesystem fuzzing, memory-safety issues, permission semantics, and syscall behavior.
- **Web3 security** — Solidity contract analysis, vulnerability detection, property-based fuzzing, and LLM-assisted auditing.
- **AI & agent engineering** — security evaluation of agent tools, automated analysis workflows, and practical LLM infrastructure.

### Open-source work

I contribute bug reports and patches to upstream systems projects:

- **[Asterinas](https://github.com/asterinas/asterinas/pulls?q=is%3Apr+author%3A1sh1ro)** — authored merged fixes for ownership changes, sticky-bit enforcement, and supplementary-group permission checks.
- **Linux kernel** — [reported an NTFS bug credited in a mainline fix](https://github.com/torvalds/linux/commit/9365c4a1357e2a5d7f1aff140429028ad292161f), and submitted [HFS filesystem patches reviewed and tested upstream](https://lkml.iu.edu/2610.2/12021.html).

I care about small, reproducible bug reports, regression tests, and patches that preserve expected system behavior.
